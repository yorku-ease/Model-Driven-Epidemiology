Phase 2 Directory Structure
===========================

phase 2/
├── .api_key.txt              ← ADD YOUR API KEY HERE
├── run_phase2.py             ← RUN THIS SCRIPT
├── requirements.txt          ← Dependencies
├── README.md                 ← Full documentation
├── INSTRUCTIONS.md           ← Step-by-step guide
├── GET_STARTED.md            ← Quick start (3 steps)
│
├── src/                      ← Source code (organized by function)
│   ├── extraction/           ← PDF processing & entity extraction
│   │   ├── pdf_pipeline.py
│   │   ├── paper_promise_extractor.py
│   │   └── entity_extractor.py
│   ├── synthesis/            ← Model generation
│   │   ├── model_synthesizer.py
│   │   └── traceability.py
│   ├── analysis/             ← Gap analysis
│   │   ├── gap_analyzer.py
│   │   └── gap_filler.py
│   ├── evaluation/           ← Quality checks
│   │   ├── quality_checks.py
│   │   └── evaluator.py
│   └── utils/                ← Utilities
│       └── llm_client.py
│
├── data/                     ← Your input data
│   ├── papers/               ← PUT YOUR PDFs HERE
│   └── baseline_models/      ← Baseline models for comparison
│
├── reports/                   ← Output (auto-generated)
│   └── [paper_name]/         ← Results for each paper
│
└── docs/                      ← Documentation
    └── [various .md files]

What to Do:
1. Add API key to .api_key.txt
2. Put your PDF in data/papers/
3. Run: python run_phase2.py --paper data/papers/your_paper.pdf --output reports/your_paper
4. Check results in reports/your_paper/
